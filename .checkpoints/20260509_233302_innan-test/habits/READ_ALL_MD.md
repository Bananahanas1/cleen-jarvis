# Read All Markdown Habit — Procedure

Purpose
- En fast vana att läsa alla markdown-filer innan nästa planering eller större ändringar för att få kontext och insikter.

How to perform (step-by-step)
- Step 1: Locate all markdown files: glob pattern **/*.md i workspace.
- Step 2: Read each file; extract headings, date stamps, decisions, blockers och relations till MVP/plan.
- Step 3: Skapa en kort sammanfattning i backlog-dokumentet (under MVP-backlog.md i docs eller i en kort logg i SESSION_LOG.md).
- Step 4: Notera eventuella beslut, risker eller nya beroenden som bör åtgärdas i backlog.
- Step 5: Return till planeringsläget med en tydlig uppföljningslista.

Output
- En sammanfattning av viktiga teman och beslut, plus eventuella uppgifter i backlog.

Note
- Läsningen bör ske innan varje större planering; det är inte en automatisk byggprocess utan en avsiktlig vana.
