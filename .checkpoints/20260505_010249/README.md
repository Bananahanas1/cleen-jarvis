# Jarvis-clean

Detta är Jarvis-clean, en ren offline-first rebuild av Jarvis.

Originalprojektet finns i:

F:\New project

Originalprojektet ska bara användas som referens. Det ska inte ändras.

Första målet är:

1. Minimal safe dashboard utan 3D/WebGL
2. Lokal Ollama-chat
3. Lokala tools, till exempel calculator
4. Stabil offline-start utan att datorn fryser

Saker som läggs till senare:

- NeuroLinked basic
- Graphify
- Obsidian
- ultraPass
- 3D-dashboard

Viktigt: starta inte gamla tunga dashboarden från F:\New project.
