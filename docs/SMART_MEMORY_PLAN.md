# SMART_MEMORY_PLAN.md — Nästa minnessystem

## Mål

Jarvis ska gå från enkelt memory.md till smartare minne.

Nuvarande minne:
- kom ihåg: text
- visa minne
- sök minne: text
- minnesstatus
- öppna minne

Nästa nivå:
- smart minne: text
- viktigt minne: text
- projektminne: text
- sammanfatta minne
- glöm minne: text

## Nytt format

Exempel:

## 2026-05-04 18:30

Type: project_fact
Importance: 4/5
Tags: jarvis, memory

Text:
Jarvis sparar lokalt minne i markdown.

## Minnestyper

- note
- important
- project_fact
- user_preference
- task
- warning
- idea
- temporary

## Säkerhet

Jarvis får inte spara:
- lösenord
- API-nycklar
- tokens
- bankinfo
- ultraPass-data
- privata hemligheter utan tydlig bekräftelse
